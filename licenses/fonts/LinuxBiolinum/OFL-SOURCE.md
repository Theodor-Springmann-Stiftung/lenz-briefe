# OFL text provenance

The complete standard SIL Open Font License 1.1 text is copied verbatim from the
OFL text already included with Cormorant Garamond, omitting that font’s separate
copyright header. Official text: https://openfontlicense.org/open-font-license-official-text/.

Linux Biolinum’s own copyright and dual-licensing declaration are preserved in
`COPYRIGHT-from-font.txt`, `font-metadata.json`, and the upstream `LICENCE.txt`.
The CTAN distribution refers to OFL.txt but does not contain it; this standard
text supplements that omission and does not invent an upstream copyright notice.
